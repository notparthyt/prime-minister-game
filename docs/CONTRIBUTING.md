# Contributing

Thanks for helping improve the game.

1. Fork the repo and create a branch: `git checkout -b feature/my-idea`
2. Keep it dependency-free: plain HTML, CSS and JavaScript.
3. Test by opening `index.html` in a browser and playing at least one full quarter, one war and one event.
4. Match the existing style: short functions, `const`/`let`, no globals beyond the game state.
5. Update `docs/` if you change rules or numbers.
6. Open a pull request describing what changed and why.

## Balance changes
Include before and after numbers (income, costs, combat odds) and why the change improves the game.

## Bugs
Open an issue with your browser, what you did, what you expected and what happened. A console error message helps a lot.
